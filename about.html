About Me

I build Android and backend systems with a product mindset and a strong focus on elegant user experience and scalable architecture.

Who I Am

I'm a Backend & Mobile Developer from Ahmedabad, India, with a passion for building polished, high-performance systems. I work across Kotlin Android apps, Go microservices, and Spring Boot backends, combining practical engineering with user-first thinking.

What I Work On

Mobile Engineering

Building Android apps with Kotlin and Jetpack Compose. I focus on clean architecture, smooth animations, and responsive user interfaces. Experience with CameraX, Maps, WorkManager, and Firebase integration.

Backend Engineering

Designing Go and Spring Boot microservices with gRPC, REST APIs, event messaging, Redis caching, and scalable data patterns. I prioritize reliability, observability, and low-latency performance.

Full Stack Products

Combining frontend and backend to build complete, end-to-end products. Experience with real-time systems, trading platforms, and logistics applications.

System Design

Building scalable distributed systems with databases (PostgreSQL, MongoDB, TimescaleDB), message brokers (Kafka, Redis Streams), and real-time synchronization.

My Approach

  • Product-First Mindset: Every line of code should serve user needs and deliver real value.
  • Clean Architecture: I write maintainable, testable code following SOLID principles and design patterns.
  • Performance Matters: Low latency, high throughput, and efficient resource usage are core to my design decisions.
  • User Experience: Smooth animations, responsive feedback, and polished interfaces are non-negotiable.
  • Continuous Learning: I stay updated with latest technologies in backend, mobile, and distributed systems.
